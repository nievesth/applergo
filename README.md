# Applergo

Applergo is the 2026 modernization of the legacy Applergic app using React + TypeScript + Vite.

## Current status

This project is in active modernization and reconstruction. The legacy project remains separate as historical reference and is not modified as part of this work.

The original legacy project was not AI-generated. It is preserved as a read-only reference while the 2026 product is rebuilt incrementally.

## Project stage

- technical baseline established
- Splash migration exists
- onboarding is currently a temporary placeholder only
- further feature migration continues incrementally

## Tooling and workflow

This project uses GitHub Copilot custom agents and skills to guide implementation and documentation.

## Local development

```bash
npm install
npm run dev
npm run test
npm run lint
npm run build
```

## Notes

- The legacy Applergic project is preserved separately as a historical reference.
- The modern project intentionally focuses on incremental migration, not full legacy feature reconstruction in one step.
